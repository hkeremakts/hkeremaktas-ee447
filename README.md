# hkeremaktas-ee447

My practice material for **EE447 – Introduction to Microprocessors** (METU, Fall 2026–27).

## ⚠️ Disclaimer

The problems, solutions and explanations here were **written with AI and checked by me**, but they can still contain mistakes.
I am a student, **not an instructor or teaching assistant** of EE447. This is simply how I practised for the course,
shared in case it helps anyone else. When something here disagrees with the lecture notes, trust the lecture notes.

## Contents

- [`index.html`](index.html) – start page: choose a week.
- [`w5/index.html`](w5/index.html) – **Week 5 Drills**: 24 practice problems on the stack, subroutines, recursion,
  delay loops, interrupts and a past-quiz-style sorting problem (Cortex-M4, Keil syntax).
- [`w6/index.html`](w6/index.html) – **Week 6 Drills**: 15 practice problems on the TM4C123's GPIO: register addresses,
  the masked data register, port initialization, switches, LEDs, seven-segment displays, a keypad, GPIO interrupts and a
  past-quiz-style port setup. Its simulator models the GPIO ports (clock gate, masked GPIODATA, DEN, the PF0 lock,
  RIS/MIS/ICR) and shows the pins as LEDs and clickable inputs.

Every page has hints, solutions and a built-in simulator that runs and checks your code for the code problems.
Each page is a single self-contained file: download it and open it in a browser.
Live version: https://keremaktas.tr/

Your "Solved" ticks and the code you type are stored only in your own browser.
